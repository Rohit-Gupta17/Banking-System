#ATM Banking System

A simple ATM Banking System developed using Python, Streamlit, and SQLite. This project simulates basic ATM operations through a user-friendly web interface.

#Features
  - User Registration
  - User Login
  - Account Number and PIN Authentication
  - 4-Digit PIN
  - Check Account Balance
  - Deposit Money
  - Withdraw Money
  - Account Details
  - Banking Transactions
  - SQLite Database
  - Streamlit Web Interface

#Technologies Used

  - Python
  - Streamlit
  - SQLite
  - HTML
  - CSS

#How to Run

  1. Clone the Repository
  git clone https://github.com/your-username/ATM-Banking-System.git
  2. Open the Project Folder
  cd ATM-Banking-System
  3. Install Streamlit
  pip install streamlit
  4. Run the Application
  streamlit run app.py

#Database

  The project uses SQLite to store banking information such as:
  
  Customer ID
  Account Number
  Name
  Email
  Mobile Number
  PIN
  Account Balance
  Account Creation Date
  
#ATM Operations
#Deposit

  Users can deposit money into their bank account.

#Withdraw

  Users can withdraw money if sufficient balance is available.

#Balance Check

  Users can view their current account balance.

#Login

  Users can securely access their account using their Account Number and 4-digit PIN.

#Project Objective

  The objective of this project is to develop a basic ATM banking application and practice:

  - Python programming
  - Streamlit application development
  - SQLite database management
  - CRUD operations
  - User authentication
  - Session management
